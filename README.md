# 🚜 Kisan Trust

> **Kisan Trust** is an AI-driven web app designed to empower farmers by bypassing unfair middleman pricing. By uploading crop photos, farmers get an instant quality assessment via Azure Computer Vision and a fair-price offer generated by Azure OpenAI. It supports 6 regional languages and features a smart Demo Mode for offline API simulation.

## Features

- **Multi-Lingual Support:** Available in 6 languages (English, Hindi, Marathi, Tamil, Spanish, French) to ensure accessibility for local farmers.
- **AI Vision Analysis:** Automatically detects vegetable type (Tomatoes, Potatoes, Onions, Carrots, Cabbages) and assesses quality/freshness using Azure Computer Vision.
- **Smart Pricing Engine:** Calculates a fair price by factoring in quality bonuses, transport, and platform fees compared to market averages.
- **Demo Mode Fallback:** If API keys are unavailable, the application gracefully falls back to a simulated "Demo Mode" ensuring the UI and flow can still be showcased.
- **Dual Implementations:** Contains both a Python (Streamlit) implementation and a Client-Side (Vanilla JS/HTML/CSS) implementation for easy static hosting.

## Technologies Used

- **Frontend / UI:** Streamlit (Python version), HTML5/CSS3/Vanilla JS (Static version)
- **AI & Backend:** Azure OpenAI (Pricing & Logic), Azure Computer Vision (Quality Check), Azure Speech Services (Text-to-Speech)
- **Styling:** Custom CSS with responsive design, glassmorphism, and micro-animations.

## How to Run (Python / Streamlit Version)

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Set up Environment Variables:**
   Create a `.env` file in the root directory. If you have your Azure keys, add them:
   ```env
   VISION_KEY=your_azure_vision_key
   VISION_ENDPOINT=your_azure_vision_endpoint
   SPEECH_KEY=your_azure_speech_key
   SPEECH_REGION=your_azure_speech_region
   AZURE_OPENAI_KEY=your_openai_key
   AZURE_OPENAI_ENDPOINT=your_openai_endpoint
   AZURE_OPENAI_DEPLOYMENT_NAME=your_deployment_name
   ```
   *(Note: If you do not provide these keys, the app will automatically run in **Demo Mode**, which simulates the AI responses perfectly for demonstration purposes!)*

3. **Run the App:**
   ```bash
   streamlit run app.py
   ```

## How to Run (Static / Netlify Version)

Simply open `index.html` in any modern web browser or deploy the directory directly to a static hosting provider like Netlify or GitHub Pages. The static version runs entirely on the client side using the built-in simulated `DemoAI`.

## Project Structure

- `app.py` - The main Streamlit application entry point.
- `azure_utils.py` - Contains all Azure API integrations (Vision, OpenAI, Speech) and the demo fallback logic.
- `index.html`, `app.js`, `styles.css` - The static client-side version of the application.
- `.env` - (Ignored by Git) Your local API keys.
